## 1. HEC-RAS 2D en Linux

Leído (Docker Hub, terceros, no USACE):

- https://hub.docker.com/r/civileng127/ras_v61 (leído): imagen que corre el motor 2D de HEC-RAS 6.1 en Linux con el ejecutable `RasUnsteady` (ej.: `RasUnsteady mac-test.c01 b01`). El Dockerfile baja `HEC-RAS_610_Linux.zip` de hec.usace.army.mil, extrae `RAS_Linux_test_setup.zip` (incluye un ejemplo Muncie, que el autor borra) y marca `RasUnsteady` ejecutable. Requiere cuatro archivos generados en Windows (`.c01`, `.x01`, `.p01.tmp.hdf`, `.b01`): el autor los obtiene corriendo HEC-RAS en Windows tras borrar `RasUnsteady.exe`, de modo que Windows solo preprocesa y no resuelve. La imagen no crea esos archivos.
- https://hub.docker.com/r/civileng127/ras_v65 (leído): lo mismo para HEC-RAS 6.5 (`Linux_RAS_v65`, base RHEL 8): `RasUnsteady <plan>.p01.tmp.hdf x01`, con `.tmp.hdf`, `.b01` y `.x01` generados en Windows. No cubre preprocesado de geometría, régimen permanente ni otros flujos. No trae proyectos de ejemplo.

Lo que dicen los buscadores (resultados no abiertos, sin verificar): la página de Wikipedia de HEC-RAS cita unas "HEC-RAS 6.1 Linux Release Notes"; una guía CLAWRIM describe el zip Linux 6.1 con `RAS_Linux_test_setup.zip` y prueba con `RasUnsteady`; el changelog de ras-commander menciona `RasCmdr.compute_plan_linux()` y una "RasPreprocess: Public API for Linux preprocessing (Phase 1)" (función de una librería de terceros, no de USACE). No se pudo abrir ninguna página oficial de HEC (notas de versión, readme Linux, descargas), así que no se confirma ni se descarta si existe un preprocesador de geometría 2D en Linux ni qué versión 6.x incluye ejemplos.

Conclusión: la documentación leída muestra que el motor `RasUnsteady` existe como binario Linux publicado por USACE (según el Dockerfile) y que calcula 2D a partir de HDF/archivos de entrada ya preprocesados. Que una geometría y un terreno NUEVOS se preprocesen en Linux está sin verificar; la ruta documentada por terceros es preprocesar en Windows. Para F4.4 esto significa: probablemente un paso en Windows con GUI (el usuario) y cálculo masivo en Linux (útil para F4.5). Pendiente: leer las notas oficiales de HEC-RAS 6.1/6.5/6.6 Linux cuando hec.usace.army.mil esté permitido en la red de la sesión.
