# Geographic references (AR catalog)

- `neuquen-province.geojson`: outline of Neuquén province. Source: Natural Earth 1:10m Admin 1 - States, Provinces
  (`ne_10m_admin_1_states_provinces`, feature `ARG-1276`), from
  https://github.com/nvkelso/natural-earth-vector. License: public domain (https://www.naturalearthdata.com/about/terms-of-use/).
  Only change: coordinates rounded to 3 decimals. Scale 1:10m, so the outline is approximate (kilometers).
  Copy of `web/public/geo/neuquen-province.geojson` (a test checks they are identical).
- `cordillera.geojson`: generated by `uv run python -m clima_nqn.stages.ar.geo` (`clima_nqn.stages.ar.geo`).
  Method: province outline ∩ the rectangle lon -71.95..-70.0, lat -41.1..-36.0, i.e. the part of the province west of
  70.0 W (Sutherland-Hodgman clip). Approximation, sin verificar. Not drawn in the viewer (removed
  2026-11-08 at the user's request); used only by the analysis.
